An original tower-defense game built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## LANTERNFALL

Defend the last lantern against 15 waves of shadow creatures. Build towers on the marked plots beside the winding stone path, spend shards earned from kills, upgrade towers to level 3, and keep the lantern's 20 lives intact. Clear wave 15 — and its Wraith boss — to win.

**Towers:** Ember Spire (50 shards, fast bolts) · Frost Ward (75, chills enemies) · Storm Coil (120, chain lightning). Click a plot to build, click a tower to upgrade or sell it.

**Controls:** mouse to build/select, keys 1/2/3 pick a tower, Space pause, Enter send the next wave, M mute, R restart.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse, no network needed.
